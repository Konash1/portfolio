# พอร์ตโฟลิโอ HengHeng

เว็บพอร์ตภาษาไทยแบบหน้าเดียว สร้างด้วย HTML, CSS และ JavaScript พร้อมภาพจริงจากเกมที่เจ้าของผลงานให้มา

## เปิดดู

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง หรือเสิร์ฟโฟลเดอร์นี้ด้วยเว็บเซิร์ฟเวอร์แบบ static

## สิ่งที่มีในเว็บ

- พอร์ตแบบสไลด์แนวนอนเต็มจอ พร้อม Intro, สแนป, วงแหวนเปลี่ยนฉาก และแถบนำทางตำแหน่งปัจจุบัน
- เปลี่ยนสไลด์ได้ด้วยล้อเมาส์/ทัชแพด, ปัดจอ, ปุ่มลูกศร และจุดนำทาง
- คารูเซลผลงานที่กดจุดนำทาง ใช้ปุ่มลูกศร หรือปัดบนจอสัมผัสได้
- ทรานซิชันประตูมิติเมื่อเปลี่ยนบท/สไลด์ พร้อมลดการเคลื่อนไหวตามการตั้งค่าระบบ
- Intro สั้นก่อนเข้าสู่หน้า Hero
- Hero และการ์ดผลงานมีการเคลื่อนไหวตอบสนองเมาส์
- ลากแถบในภาพ Streaming Night เพื่อเปิดดูและเปรียบเทียบสองฉาก
- โปรเจกต์ Prototype TD และ Streaming Night พร้อมภาพและลิงก์เกม
- ตัวเลือกโลกผลงาน, Dev Log แยกแต่ละเกม และภาพ Prototype TD แบบเห็นภาพเต็ม
- ปุ่มเปิด/ปิดเสียงบรรยากาศแบบสร้างในเบราว์เซอร์
- Easter egg ที่สัญลักษณ์ดาว และทางเลือกท้ายพอร์ตสำหรับเปิดเกม/ติดต่อ
- เปลี่ยนสไลด์ด้วย transition อย่างเดียว: ขาไปเปิดวงกลม ขากลับหุบวงกลมและปัดสวนทาง
- หน้าต่างรายละเอียดโปรเจกต์และแถบเปรียบเทียบภาพ Streaming Night แบบลากได้
- ส่วนแนะนำตัว ทักษะ และเส้นทางการเรียนรู้
- ช่องทางติดต่อ พร้อมปุ่มคัดลอก Discord
- รองรับ `prefers-reduced-motion`
